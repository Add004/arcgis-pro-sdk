## Remarks

<p>Dynamic segmentation is the process of computing the map location (shape) of events stored in an event table.</p>
<p>The shapes of a route event source cannot be edited because they are generated by the dynamic segmentation process. When you edit a route
     event, you are editing the underlying event table.</p>
<p>Dynamic segmentation allows multiple sets of attributes to be associated with any portion of a linear feature.</p>
